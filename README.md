# berkenan.id — Undangan Digital

<img src="assets/logo/logo-mendatar-terang.png" alt="berkenan.id, undangan digital" width="300">

Situs jualan undangan digital untuk pernikahan, khitan, ulang tahun, dan acara umum: landing page, 7 tema (Maroon, Moss, Vintage, Noir Gold, Islami, Ceria, Modern), tool admin, dan RSVP lewat Google Sheets. Semuanya statis (HTML/CSS/JS), tanpa server atau database.

- **Situs:** https://ivan42118.github.io/berkenan.id/
- **Contoh undangan:** https://ivan42118.github.io/berkenan.id/undangan/?u=demo-maroon&to=Tamu+Spesial
- **Buat undangan:** https://ivan42118.github.io/berkenan.id/admin/buat-undangan.html
- **Generator link tamu:** https://ivan42118.github.io/berkenan.id/admin/link-tamu.html

Panduan lengkap (pengaturan, deploy, alur pesanan, strategi jualan): [PANDUAN.md](PANDUAN.md). File logo siap pakai ada di [assets/logo/](assets/logo/).

python -m http.server 5500
